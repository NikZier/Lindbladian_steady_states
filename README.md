# Strong-to-weak spontaneous symmetry breaking in dissipative spin chains

Code and data for the publication *[title, authors, journal/arXiv to be added]*.

This repository computes non-equilibrium steady states of Lindblad master
equations on spin-1/2 chains with tensor networks and exact sector solvers. It
uses them to study **strong-to-weak spontaneous symmetry breaking (SWSSB)** of a
strong ℤ₂ parity symmetry. It contains:

- `lindblad_mps/`: the numerical library. It covers finite-chain MPS/TEBD for
  vectorized density matrices, infinite-system iTEBD, a Liouvillian MPO for
  steady-state residuals, and exact dense and matrix-free symmetry-sector
  steady-state solvers.
- `experiments/`: one script per numerical study, grouped into one folder per
  model plus `benchmarks/` (§6). Each folder keeps the pickles and diagnostic
  figures its scripts write in its own `results/` subfolder.
- `experiments/cache/`: every completed simulation, one pickle each, shared by
  all studies, so the figures can be reproduced without re-running hours of
  TEBD.
- `experiments/paper/`: the publication figures (PDF) and
  `figures_paper.ipynb`, the notebook that draws them.
- `tests/`: a pytest suite that checks the library against exact
  diagonalisation and known analytic limits.

## 1. Physics setup

### Strong symmetry and the diagnostic

All models are defined on a chain of N qubits with nearest-neighbour bond
terms. Each one has a **strong** ℤ₂ symmetry generated by the parity
P = Z₁Z₂…Z_N. Every jump operator commutes with P individually, not only the
superoperator. The Liouvillian therefore splits into independent blocks labelled
by the parity charges (q_L, q_R) of the ket and the bra. All simulations
start in, and stay in, the (+,+) sector.

A two-site operator commutes with the global P exactly when it commutes with
Z⊗Z on its own bond. This local condition is what makes it possible to draw
random symmetric perturbations bond by bond.

SWSSB is the phase where the steady state loses the strong symmetry but keeps
the weak one. No linear observable can detect it. The diagnostic used
throughout is the **Rényi-2 correlator**, which is quadratic in ρ:

    R(i,j) = Tr[ρ A ρ† A†] / Tr[ρ† ρ],      A = X_i X_j

**Long-range order, meaning R(i,j) does not decay with |i − j|, is the SWSSB
signal.** For a physical ρ, R ≥ 0, because it is the trace of a product of two
positive semidefinite matrices. A negative value therefore measures how much
positivity truncation has destroyed, and it is recorded for every run.

### Model 1: dissipative pair annihilation with a random symmetric jump

Purely dissipative (H = 0). Every nearest-neighbour bond carries three jump
operators at rate 1:

    L   = X_a X_{a+1} (1 − Z_a Z_{a+1})          Hermitian, annihilates |0…0⟩
    L'  = X_a X_{a+1} (1 − Z_a)(1 − Z_{a+1})     non-Hermitian, annihilates |0…0⟩
    L'' = random operator on the 8-dimensional commutant of Z⊗Z,  ‖L''‖ = ε

In particle language (|1⟩ = particle), L is symmetric hopping and L' = 4|00⟩⟨11|
is pair annihilation, so the baseline is the critical reaction-diffusion process
A + A → ∅. The vacuum |0…0⟩ is a dark state of the baseline. A generic L'' has a
**pair-creation** matrix element c = ⟨11|L''|00⟩. That turns the process into
A + A ⇌ ∅ and gaps the Liouvillian at order q ≡ |c|² ∝ ε².

Ten random L'' are drawn from fixed seeds (`renyi2_swssb.draw_samples`). They are
labelled sample 0–9 everywhere.

### Model 2: driven classical circuit (biased hopping + pair annihilation)

A classical two-site Markov process written in Lindblad form, with one jump
operator per transition:

    L_R = √p |01⟩⟨10|,    L_L = √(1−p) |10⟩⟨01|,    L_A = √γ_A |00⟩⟨11|

The bias is p = 0.8 (p = 1/2 is unbiased) and all rates are 1. The ten L''
seeds and the ε values are the same as in Model 1, so samples can be compared
model against model. At p = 1/2, hop rate 8 and γ_A = 16, Model 2 reproduces
Model 1's steady-state correlator to relative precision 1e-6.
Code: `models.classical_drift_annihilation_jump_operators`.

### Model 3: Hamiltonian (coherent) perturbation of Model 1

Same dissipative baseline as Model 1 (L, L′), but the random perturbation is a
Hermitian nearest-neighbour Hamiltonian H = Σ_a h_{a,a+1}, with h commuting with
Z⊗Z and ‖h‖ = ε. Here h drives |00⟩ ↔ |11⟩ coherently with amplitude
c = ⟨11|h|00⟩. Adiabatic elimination against γ_A gives an effective incoherent
pair-creation rate ∝ |c|². The draws use their own seed (`HAM_BASE_SEED`).

### Initial states

- `zero` = |0…0⟩⟨0…0|, the dark state of the baseline. It approaches the steady
  state from R = 0.
- `neel` = |0101…⟩⟨0101…|. It is not dark, starts with large correlations and
  approaches from the other side.

Both lie in the (+,+) sector for every N that is used.

## 2. Main results (summary)

| | Finite N | Infinite chain (iTEBD) |
|---|---|---|
| **Model 1** | R flat in N and in separation; **R = q/8** (N ≤ 16, χ = 128) | R flat to r = 100; **R = q/4** (ε → 0 intercept 0.2500015) |
| **Model 2** (p = 0.8) | Ring: R/q → 2 = 2/γ_A. Open chain: R falls with N because of an inflow-boundary effect of the drift | R flat to r = 100 in all 40 runs; **R = 4q/γ_A** |
| **Model 3** | R ∝ ε² exactly (exact sector solves); R/\|c\|² = 0.0231 (N=4) → 0.0216 (6) → 0.0213 (8) → 0.0211 (12) | not computed (cost, see §5) |

In all three models the SWSSB amplitude is set by the pair-creation matrix
element alone. In the unbiased case the hopping rate drops out entirely. The
deviations from the leading-order laws are clean O(ε²) corrections. For
example, Model 1 iTEBD gives R/q = ¼ (1 − 0.036 ε²).

The tests below were run because each failure mode has, at some point,
produced a convincing but wrong answer. Each row names the script and the
output to look at. Studies whose only purpose is a check live in
`experiments/benchmarks/`. Checks built into a production study (controls,
two initial states, long-schedule re-runs, the Model 3 χ sweep) stay with that
study in its model folder.

| Check | Result | Where |
|---|---|---|
| χ sweep, Model 1, N=20, sample 0 | χ = 32 and 64 are χ-limited and **fabricate** an exponential decay. At χ=128 the final bond is 71 < 128 (cutoff-limited) and R(20)/R(16) = 0.989 | `renyi2_swssb.py`, `renyi2_swssb_chi64.py`, `renyi2_swssb_chi_extended.png` |
| χ sweep, Model 3, N ∈ {12, 14, 16} | χ=128 is corrupted at N=12; χ=256 agrees with χ=320 to ≤ 0.74% at N=16 | `ham_finite_size.py --convergence`, `ham_finite_size_convergence.pkl` |
| χ sweep, Model 2, N=20, sample 8 | 3.00e-4 (χ=32), 3.29e-4 (χ=64), 3.70e-4 (χ=128, bond 64) | `renyi2_drift_annihilation_chi.png` |

Every finite run stores `final_bond_dims` and `max_discarded_weight`. A run
whose bond dimension reaches χ at any point during the run gives only a lower
bound, even if its final bond is small.

### 4.3 Relaxation (evolved time)

| Check | Result | Where |
|---|---|---|
| Liouvillian residual r = ‖ℒ\|ρ⟩‖/‖\|ρ⟩‖, compared with the dt² Trotter floor (C = 0.0202 at N=4) and divided by the gap of the slowest mode | recorded for every finite run | `lindblad_mps/residual.py` (MPO of bond dimension 18) |
| Stage-by-stage R as dt is annealed | recorded for every run (`stage_correlators`, `stage_drift`) | all finite scripts |
| Two initial states (`zero` vs `neel`), Model 1 finite | 0.00% (N=4, 8), 0.21% (N=12), 3.75% (N=16, worst sample); N=20 differs by up to 26% (under-relaxed) | `renyi2_swssb_init_comparison.png` |
| Two initial states, Model 1 iTEBD | ≤ 0.2% for all 10 samples | `imps_zero_vs_neel_infinite.png` |
| iTEBD schedule length scales as 1/ε², checked with 5× longer controls | sample 8, ε=0.05: 2.7717e-5 (240 240 units) vs 2.7714e-5 (47 040 units) | `imps_eps_init_grids.py` (`*long` kinds), `imps_sample8_long.png` |
| Model 2 iTEBD schedule sized per sample as 12/q before the run; 3×-length control | identical to six digits | `imps_drift_eps_grids.py` (`driftinf_long`) |
| Plateau time of the iTEBD at ε=0.2 | sets the 2940-unit schedule | `imps_schedule_length_check.py` |

Two warnings about relaxation:

1. **Agreement between the two initial states is not proof of relaxation.**
   Both starts quickly fall onto the same slow manifold (decay rate ~ q) and
   then drift along it together. Only a reference that does not depend on the
   trajectory settles convergence: the residual divided by the slow gap, an
   exact solve, or a schedule sized from 1/q before the run.
2. **Small residuals can mislead.** Because r ≈ gap × distance, a slow mode can
   leave a state far from the fixed point while r sits near the Trotter floor.

## 5. Known limitations

- **Model 1, N = 20**: the fixed 5 × 300-step schedule does not fully relax
  every sample, and the two starts differ by up to 26%. Use the zero/neel spread
  as the error bar, or N ≤ 16. Samples 1 and 9 reach the χ=128 cap at N=20.
- **Model 3, N = 16** (`ham_finite_size_highchi.pkl`, χ=256): not relaxed
  (ensemble spread 24–96%, drift up to 15%). This row is in the export table
  but is **not** used in the figure (the notebook filters to N < 14).
- **Model 3 iTEBD**: abandoned as unaffordable, because the Hamiltonian flow
  saturates χ=128. `imps_ham_eps_grid.py` is kept because it defines the
  Model 3 ensemble and the schedule sizing that `ham_finite_size.py` imports.
- **Model 2, OBC exact solves**: `drift_circuit_exact_finite.py` lists
  N = 14 in `SIZES`, but the N=14 run is incomplete (37 of 52 solves are in the
  cache). The published pickle and figure contain N ≤ 12 only.
- **Reproducibility across machines**: truncated non-unitary TEBD amplifies
  differences in BLAS summation order. At χ=32 the same run differs by 5–12%
  between machines, while at converged χ the difference is negligible.
  Recompute a study on one machine rather than mixing cache entries.

## 7. Reproducing the results

Requirements: Python ≥ 3.11 and [uv](https://docs.astral.sh/uv/). The pinned
environment is in `uv.lock`.

    uv sync                     # create the environment
    uv run pytest               # test suite (187 tests, ~3 min)

**Redraw the paper figures from the shipped data** (seconds; Jupyter is not a
project dependency):

    cd experiments/paper
    uv run --with jupyter jupyter lab figures_paper.ipynb

The notebook reads from `../model*/results/` and writes the PDFs next to
itself, so start it from `experiments/paper/`.

**Rebuild the figure data from the cache** (no simulation):

    uv run python experiments/model1_dissipative/imps_analytic_prediction_data.py
    uv run python experiments/model3_hamiltonian/ham_finite_size_export.py

**Re-run studies.** Each script first looks for its jobs in `experiments/cache/`.
A cached job is reused only if its stored `run_config` (dt schedule, steps,
cutoff, recanonicalisation interval) matches. Delete a cache file to force a
recompute. Approximate wall-clock times with 12 worker processes on a
6-core/12-thread desktop:

| Command | Time |
|---|---|
| `uv run python experiments/model1_dissipative/renyi2_swssb_chi128.py` | ~2.7 h per initial state |
| `uv run python experiments/model2_drift/imps_drift_eps_grids.py` | ~3.9 h (46 jobs) |
| `uv run python experiments/model2_drift/drift_circuit_exact_finite.py` (N ≤ 12) | ~1 h on 6 workers |
| `uv run python experiments/model2_drift/drift_circuit_exact_finite_pbc.py` | ~1 h on 6 workers |
| `uv run python experiments/model3_hamiltonian/ham_finite_size.py` | ~2 h (χ=128) |
| `uv run python experiments/model3_hamiltonian/ham_finite_size.py --highchi` | ~20 h at N=16, χ=256 |

The number of worker processes is `N_WORKERS` in `experiments/model1_dissipative/renyi2_swssb.py`.
Use about the number of hardware threads. When redirecting output to a log on
Windows, set `PYTHONIOENCODING=utf-8`, because the reports contain non-ASCII
characters.
